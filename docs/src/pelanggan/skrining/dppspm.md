# DPPSPM

Menu: **Pelanggan → Skrining → DPPSPM**

Daftar Pendanaan Proliferasi Senjata Pemusnah Massal terbitan PPATK, berisi sanksi Dewan Keamanan PBB untuk Korea Utara (DPRK) dan Iran (IR). Nama pelanggan, beserta seluruh alias di daftar ini, dicocokkan otomatis setiap kali transaksi disimpan, sama seperti [DTTOT](/pelanggan/skrining/dttot).

![Tab DPPSPM: kotak ringkasan, filter jenis dan rezim, serta tabel daftar](/pelanggan-skrining-dppspm.png)

## Isi halaman

| Bagian | Isi |
|---|---|
| **Entri Daftar** | Jumlah entri dari seluruh rezim sanksi |
| **Individu** / **Entitas** | Jumlah entri orang dan badan, sesuai sheet Individu dan Entitas di berkas PPATK |
| **Terakhir Diperbarui** | Tanggal impor terakhir |
| **Jenis Subjek** | Saring **Individu** atau **Entitas** |
| **Rezim Sanksi** | Saring **DPRK** atau **IR** |
| **Cari** | Nama, alias, atau referensi |
| **Referensi** | Nomor referensi PBB untuk entri itu |
| **Nama** | Nama beserta aliasnya |

Klik **⋮ → Detail** di ujung baris untuk melihat seluruh data satu entri.

## Mengekspor daftar

Klik **Ekspor**, lalu pilih formatnya. Lihat [Tabel, Filter, dan Ekspor](/mulai/tabel-dan-filter).

## Aturan

- **Satu daftar untuk semua perusahaan.** Seperti DTTOT, mengubah, menghapus, dan mengimpor DPPSPM hanya bisa dilakukan oleh pengelola sistem ValasPro.
- **Impor memakai berkas PPATK apa adanya.** Pengelola mengunggah berkas .xlsx terbitan PPATK lewat **Impor Daftar DPPSPM**. Entri dengan **Referensi** yang sudah ada diperbarui, dan entri baru ditambahkan.
- **Alias ikut dicocokkan.** Pelanggan bisa tersaring karena namanya mirip dengan salah satu alias, bukan nama utama. Periksa kolom Nama untuk melihat aliasnya.
